{{- /* Én trening -> tekstlig form, brukt av lagkortene (lagliste og lagvelgeren). Treningene lagres strukturert (fra/til/sted/bane) for timeplanen, mens kortene vil ha "18:30 - 20:15" og "Åshallen, gammel del". Sammensettingen ligger her, så de to visningene aldri kan formulere seg ulikt. Banen tas bare med når hallen har `visBaneIKort: true`. På Åsgård Skole er banefordelingen tentativ og hører hjemme i timeplanen, ikke i lagkortet. I Åshallen er "gammel del" og "ny del" derimot det eneste som skiller Tullballs to økter fra hverandre, så der må den med. Returnerer dict med "tid" og "sted". */ -}} {{- $t := . -}} {{- $sted := $t.sted -}} {{- $hall := index (where hugo.Data.lag.haller "navn" $t.sted) 0 -}} {{- if and $hall $hall.visBaneIKort -}} {{- $baner := $t.bane -}} {{- if not (reflect.IsSlice $baner) -}} {{- $baner = slice $baner -}} {{- end -}} {{- /* "Ny del" -> "ny del", så det leses som en fortsettelse av stedsnavnet */ -}} {{- $sma := slice -}} {{- range $baner -}} {{- $sma = $sma | append (lower .) -}} {{- end -}} {{- with $sma -}} {{- $sted = printf "%s, %s" $sted (delimit . ", " " og ") -}} {{- end -}} {{- end -}} {{- with $t.notat -}} {{- $sted = printf "%s (%s)" $sted . -}} {{- end -}} {{- return dict "tid" (printf "%s - %s" $t.fra $t.til) "sted" $sted -}}
